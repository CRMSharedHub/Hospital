# Workforce privacy / HIPAA training checklist

Track completion outside git (HRIS). Use this list for content coverage.

## Audience

- [ ] Admins  
- [ ] Physicians  
- [ ] Nurses  
- [ ] Billing / front desk  
- [ ] IT / contractors with PHI access  

## Topics (minimum)

1. [ ] What is PHI / when it may be disclosed  
2. [ ] Minimum necessary access  
3. [ ] Password + MFA requirements  
4. [ ] Phishing awareness  
5. [ ] Secure workstation / screen lock  
6. [ ] No PHI in personal email / WhatsApp  
7. [ ] Reporting incidents (link to breach playbook)  
8. [ ] Facility / role boundaries (multi-campus)
