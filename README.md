# Hospital Management Dashboard

A modern, responsive hospital management dashboard built with React, Vite, Tailwind CSS, and Lucide icons.

## Features

- Dashboard overview with stats and weekly activity chart
- Patients list with search
- Doctors directory with availability and ratings
- Appointments management with status filters
- Arabic / English language toggle with RTL support

## Getting Started

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## Project Structure

```
src/
  components/   # Reusable UI components
  pages/        # Dashboard, Patients, Doctors, Appointments
  data/         # Mock data
  i18n.jsx      # Language context and translations
  App.jsx       # Routing
```

## Build

```bash
npm run build
npm run preview
```
